# Sample Page

This is a sample page. Use it as a starting point when you add new pages to the help center.

## Headings and text

Write in short paragraphs. Use **bold** for UI labels, such as **Dashboard → Bids**, and `inline code` for values a reader types.

## Steps

1. Open the dashboard.
2. Go to **Bids**.
3. Select **Compact Console** to switch to the compact view.

## Table

| Setting    | Default       | Description                       |
| ---------- | ------------- | --------------------------------- |
| View mode  | `traditional` | Layout used on the Bids page.     |
| Page size  | `25`          | Number of bids shown per page.    |

## Code block

```json
{
  "viewMode": "compact",
  "pageSize": 25
}
```
